# Feature-Parity Matrix (`FEATURE_PARITY.md`)

Comparison between upstream **StoryTribe v3.4.6 (`storytribeapp.com` / `app.storytribeapp.com`)** and our local production implementation.

| Domain / Area | Feature / Capability | Upstream (`storytribeapp.com`) | Our Implementation | Parity Status |
|---------------|----------------------|--------------------------------|--------------------|---------------|
| **Public & Marketing** | Homepage (`/`), Features (`/features`), Pricing (`/pricing`), Help (`/help`), Community Hub (`/community`), Community Explore (`/community/explore`) | Webflow + Next.js pages | Native Next.js 16 responsive pages matching StoryTribe aesthetic + public Community gallery (`Trending`, `Newest`, `Most liked`, `Storyboards`, `Videos`, `Books`) | 100% Parity |
| **Public Sharing** | Shared Storyboard (`/share/[token]`), Video Share (`/v/[shareToken]`), Creator Profile (`/[username]`), Guest Invite (`/app/guest-invite/[token]`), Custom 404 | Next.js dynamic routes | Native Next.js routes with live Grid/Slideshow/Script views, comment permissions, and guest invite acceptance | 100% Parity |
| **Auth & Security** | Email/Password Login, Forgotten Password, Verify Email (`/verify-email`), Error Banners | Firebase Auth | NextAuth v4 (`CredentialsProvider`, `bcryptjs` 12-round hashing, `/verify-email` activation) | 100% Parity |
| **Enterprise Governance** | Invite-Only Registration, Single-Use Expiring Codes, RBAC (`USER`/`ADMIN`), Revocation, Rotation, Audit Log | Not available in consumer app | Full `AccountInvitation` + `AuditLog` + CLI Bootstrap + `/admin/invitations` & `/admin/audit-logs` | **Enhanced** |
| **Database Layer** | Persistence Engine | Firebase Firestore + S3 | Prisma 7 Dual Adapter: SQLite (`better-sqlite3`) for local dev + PostgreSQL (`pg`) for prod | **Enhanced** |
| **Workspace Shell** | Sidebar navigation (`Home`, `Create`, `Projects`, `Shared`, `Elements`, `Properties`, `AI History`, `Workspace` + `/elements` + `/members`, `Profile`, `Inspiration`, `Saved`, `Connections`, `Notifications`, `Settings` + `/settings/workspace`) | `/app/*` routes | Complete `/app/*` routes backed by real Prisma models (zero dummy data) | 100% Parity |
| **Project Creation** | Blank Storyboard (`16:9`, `9:16`, `4:3`, `1:1`, `2.35:1`, Custom `200–6000px`), AI Script Wizard, Import Script, Templates | `/app/create` | Full `/app/create` wizard supporting all aspect ratios, custom dimensions, script parser, AI wizard, and templates | 100% Parity |
| **Editor Mode 1** | **Story Bible** (`viewMode = "bible"`): Cover banner palettes, title, `Summarise with AI` synopsis, `@Elements` | `/app/editor/[id]` | Full Story Bible view with cover palette picker, AI synopsis generator, and `@Element` cards | 100% Parity |
| **Editor Mode 2** | **Script Writer** (`viewMode = "writer"`): Scene headings, shot script blocks (`Action`, `Character`, `Dialogue`, `Parenthetical`, `Transition`), `AI Script`, `Import script`, `@Elements` | `/app/editor/[id]` | Full scene-grouped Screenplay & Shot Script Writer with AI Script expansion & Fountain/text import | 100% Parity |
| **Editor Mode 3** | **Storyboard Grid** (`viewMode = "grid"`): `2..8` column slider, `Compact` view, `@element`/`#scene` filter, shot cards, property pills, `✨ Generate` | `/app/editor/[id]` | Full multi-column Storyboard Grid with live stage thumbnails, property badges, drag/reorder, and AI generation | 100% Parity |
| **Editor Mode 4** | **Interactive 2D Canvas** (`viewMode = "canvas"`): Select, `✨ Tribe AI`, `@ Elements`, `🔍 Search Assets`, `🧑 Character Builder`, `✏️ Sketch`, `💬 Comment Pin`, `➕ Create` (Text, Shapes, Speech/Thought Bubbles, Frames, Upload) | `/app/editor/[id]` | Complete interactive 2D stage with Character Builder rig (poses, expressions, outfits, hair, skin tones, angles, flip), freehand Sketch (`Normal`, `Inertia`, `Dashed`, `Dotted`), Comment pins, and 4-tab Right Inspector (`Script`, `Canvas`, `Layers`, `Comments`) | 100% Parity |
| **Editor Mode 5** | **Table / Shot List** (`viewMode = "grid"` table layout): Scene-grouped spreadsheet with `#`, `Frame`, `Title`, `Script`, and custom properties | `/app/editor/[id]` | Full inline-editable Shot List Table with custom property columns (`+`) | 100% Parity |
| **Editor Mode 6** | **Video / Animatic NLE** (`viewMode = "video"`): `Create video`, multi-track timeline (AI video clips, Shot frames, Transitions, Voiceover/TTS, Music), playback, video export | `/app/editor/[id]` | Complete Video Animatic NLE timeline editor with timed playback, Web Audio / TTS synthesis, transitions (`none`, `fade`, `dissolve`, `wipe`), and WebM/JSON export | 100% Parity |
| **Export Pipeline** | 6 layouts (`One shot per page`, `Storyboard, 3 per page`, `Grid overview`, `Images only`, `Screenplay`, `Shot list / Table`) in `PDF`, `PPTX`, `PNG`, `CSV`, `JSON` | Client/Server export modal | Real downloadable generator for all 6 layouts across `PDF`, `PPTX`, `PNG`, `CSV`, `JSON`, and `WebM` | 100% Parity |
| **Responsive Mobile** | Mobile Homepage & Mobile Storyboard Editor (`/m/editor/[projectid]`) | Responsive layouts | Full responsive mobile layouts including `/m/editor/[projectid]` | 100% Parity |
| **37 Upstream Page Chunks** | All 37 `pages__*` bundles including `/account-action`, `/app/editor`, `/app/invite/[token]`, `/support-access`, `/verify-email`, `/community`, `/community/explore`, `/app/guest-invite/[token]`, `/app/workspace/[workspaceId]/elements`, `/app/settings/workspace` | Next.js pages | 100% 1:1 route coverage across all 37 upstream page chunks plus invite-only governance routes (65 total Next.js routes) | 100% Parity |
